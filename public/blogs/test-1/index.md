为什么有些封装型产品能成长为十亿美元级公司，而另一些却迅速被淘汰。

“那不过是个AI外壳而已。” 

这种贬低感，对那些正利用人工智能开发新事物的人来说，似乎并不陌生。 

这种反弹的感觉同样令人熟悉。 

“一切皆是包装。OpenAI 是 NVIDIA 和 Azure 的封装，Netflix 是 AWS 的封装，而 Salesforce 则是以 3200 亿美元估值的 Oracle 数据库封装，”Perplexity 首席执行官阿拉文德·斯里尼瓦斯表示 ”。

对于不熟悉“AI Wrapper”这一术语的人，这里有一个不错的定义²。

这是一个带有轻视意味的术语，指的是一种轻量级的应用程序或服务，它利用现有的AI模型或API来提供特定功能，通常在创建过程中几乎无需投入太多精力或避免复杂性。一个典型的AI封装应用示例，就是那些让用户能够与PDF“聊天”的工具。这类AI应用允许用户上传PDF文档——比如研究论文——并借助AI模型快速分析内容，即时获取相关问题的答案。在ChatGPT问世初期，用户还无法直接将文档作为提示的一部分上传，也无法自定义专属的GPT模型，因此这些应用迅速蹿红，广受欢迎。 

图片
在我看来，这场关于AI封装的争论忽略了一个更重要的问题。并非所有封装都是一样的——有些昙花一现，仅能维持到大型平台将其整合进自己的生态系统中；但那些能够扎根于用户工作场景、积累专有数据并从实际使用中不断学习，或成功抵御现有渠道优势的产品，则有望长久立足。事实上，所谓的“封装”标签反而分散了我们对真正关键问题的注意力：（1）它究竟是一个功能，还是一款独立产品？（2）这一细分市场的规模究竟有多大？ 

功能或产品 

让我们先来看看之前那个能让你与PDF对话的封装工具。这类工具有效解决了关于文档提问这一特定的小问题，但并不能创建新文档或编辑现有文件。通常，它也无法捕捉任何独特数据，更不会根据用户行为进行学习。因此，在我看来，这更像是一种功能，而非端到端的解决方案——一种实现目标的手段。 

最后，如果可以的话，这类功能应内置于文档查看器或编辑器中，亦或是模型提供商的旗舰应用里。当这些基础模型本身（如OpenAI/ChatGPT、Anthropic/Claude、Google/Gemini）原生集成这一功能时，独立的工具便变得多余了。这正是典型的功能特性表现——易于复制，缺乏端到端的完整价值，也无护城河可言，更难形成长期的防御优势。 

不过，需要注意的是：即使是那些原本属于功能的特性，也可能发展成颇具潜力的独立企业，为它们带来可观的收入，直到各大平台将其直接整合到自己的应用中。 

PDF.ai月经常性收入50万美元，PhotoAI月经常性收入7.7万美元，Chatbase月经常性收入7万美元，InteriorAI月经常性收入5.3万美元。 

Jenni AI在短短18个月内，月经常收入从2000美元飙升至超过33.3万美元。 

大到不容忽视 

有些封装产品是正品，但它们所处的市场细分领域规模庞大，以至于模型制造商和大型科技平台都无法忽视。竞争主要体现在两个方面：（1）模型获取，以及（2）渠道分销。 

模型访问 

代码助手完美体现了这一点。像Cursor这样的工具，已将传统代码编辑器升级为集成了人工智能的集成开发环境（IDE），能够自动读取代码库、编辑文件、生成代码、撤销更改，甚至运行编码代理，彻底重塑了开发者在AI时代的体验。这一市场前景广阔，备受关注——截至2025年10月，全球市值排名前五的公司中，约有30%的员工是软件开发者，而这些公司无一例外均为科技企业。即便是小幅提升生产力的开发工具，也能释放出数十亿美元的价值。因此，这一领域自然成为模型开发者以及已拥有成熟分销渠道的行业巨头们争相布局的热门目标。 

但Cursor及其他类似工具几乎完全依赖于访问Anthropic、OpenAI和Gemini的模型，直到开源的开放权重模型以及公司自研模型在质量上能够媲美或超越前沿级模型为止。开发者论坛上充斥着付费订阅用户抱怨速率限制的声音。在我自己的项目中，我甚至在项目进行到一半时就用完了Cursor中的Claude额度——尽管我更喜欢Cursor的用户界面和设计，最终还是转而使用Claude Code（为此支付了十倍的费用，以规避速率限制）。虽然Claude的界面可能更出色，但能否顺畅调用模型，却成了决定性因素。 

该模型访问依赖性不仅涉及速率限制，更具有战略意义。OpenAI首席执行官山姆·阿尔特曼认为，正确的策略应以持续改进模型为前提：

“目前有两种策略可以依托人工智能发展。一种策略是假设模型不会再有进步；而另一种策略则是假定模型将继续以同样的速度不断优化。在我看来，全球95%的机构应该押注于后一种情况，但许多初创公司却选择了前一种模式。不过，只要我们专注于自己的核心使命，脚踏实地地做好本职工作，最终必将彻底击败你们！” 

基础模型竞赛已扩展至OpenAI应用公司首席执行官菲迪·西莫明确列为战略领域的各个类别（知识/辅导、健康、创意表达及购物），以及其他如写作助手、法律助手等大型市场细分领域。 

分销

分销构成了第二大威胁。即便模型开发者选择不直接参与，初创企业仍需面对一个截然不同的竞争问题——它们能否以更快的速度建立起用户群，从而领先于那些已拥有成熟产品和强大分销渠道的行业巨头，并成功为其产品添加AI功能？这正是微软Teams与Slack之间经典的“动态竞争”案例。当前的挑战在于：如何在微软将Copilot深度整合到Excel和PowerPoint、谷歌将Gemini无缝融入Workspace，或Adobe将其AI技术全面嵌入旗下创意工具套件之前，率先赢得一批忠实客户？因此，针对电子表格或演示文稿推出的独立AI解决方案，不仅要实现功能上的全面对等，还需克服捆绑销售与分销优势，以及用户转换时所面临的高昂成本。 

这种由现有企业主导的分销竞争现象，同样存在于医疗和法律等其他大型市场中。在这些市场中，监管障碍以及对核心系统的掌控，往往使Epic Systems等行业巨头占据优势。例如，一款无法直接向电子健康记录（EHR）写入数据的临床病历生成工具，迟早会遭遇Epic的分销优势，难以立足。 

这里有三点需要特别注意：  

（1）首先，快速进入市场即使缺乏长期的护城河，也可能催生退出机会；例如，像Cursor这样的工具可能对其核心依赖关系（模型访问权）缺乏掌控，但其迅猛的增长速度却使其成为那些渴望迅速抢占市场的模型开发者眼中的诱人目标。  

（2）其次，卓越的执行力有时甚至能战胜结构性优势——尽管Meta拥有远超对手的庞大预算和强大分发能力，但Midjourney出色的产品质量仍成功打动了Meta，促使后者选择与其合作。  

（3）最后，基础模型或许能够避开某些规模庞大的市场；比如，在医疗和法律领域面临的严格监管压力，或是因AI伴侣或成人色情内容而可能引发的声誉风险，这些因素反而可能为那些愿意直面极端监管审查或争议的从业者创造机遇。 

机会依然巨大，但竞争（或收购）可能随时敲门而来。

Cursor 在 18 个月里从零增长到每年 1 亿美元的经常性收入，并多次成为有关被 OpenAI 收购传闻的对象；Windsurf ，另一款代码助手，从 Google 那里获得了一份 24 亿美元的收购授权协议；Gamma 用大约一年的时间达到了 5000 万美元的收入；Lovable 只用了六个月就实现了 5000 万美元的收入；Galileo AI 被 Google 收购，但金额未披露。

创业者面前的机会

并非每个市场空白都能吸引模型构建者或科技巨头。事实上，存在着一大批规模虽不足以吸引风险投资，却足以支撑数百万美元企业的小众领域。这些细分市场正适合那些精打细算、注重专注度和精益运营的创业者。 

不妨考虑那些占星术、显化或梦境解析AI应用。比如，一款梦境解析工具，它能让用户每天早晨记录自己的梦境，根据梦境生成AI视频，同时帮助用户维护一份专属的梦境日志，并逐步揭示其中的规律——这简直能完美解决用户的需求！当然，用户也可以直接向ChatGPT描述梦境，后者甚至会保存历史记忆，但专门开发的App能够以更结构化的方式捕捉梦境信息，预设多个特定字段（如反复出现的人物、地点、物品或主题等），并深度整合睡眠追踪数据——这些功能往往是通用型聊天机器人难以实现的。尽管这类细分市场足够小，足以避开模型竞争的焦点，但其规模似乎又足以支撑起一家盈利的独立创业公司。 

模型 vs. 现任者 

虽然之前的几类为新创业企业提供了机遇，但当模型构建者涌入时，现有企业也将在包装层的争论中面临各自的战略选择。在我看来，那些成功应对模型构建者竞争的企业将具备两个共同特征。 

1. 首先，即使他们并不拥有模型，也能掌控最终结果。那些已嵌入用户工作流程的应用程序（如Gmail/日历、表格、电子健康记录/电子病历、Figma）无需用户养成新习惯；而从零开始构建这些平台，远比在现有平台上添加AI功能更为困难。当这些应用直接将操作指令导入企业专有的记录系统中（例如管理日历事件、提交理赔申请、生成采购订单等），“完成”便自然发生在现有企业的环境中——此时，AI仅成为现有工作流的又一输入工具，而非对其构成替代。 

2. 其次，成功的现有企业将基于客户使用情况构建专有数据。修正、边缘案例、审批流程以及任何人工反馈，都将成为训练数据，帮助产品不断优化升级——而这些数据正是前沿模型无法获取的。尽管Cursor并非现有企业，且其发展依赖于外部模型，但公司仍计划通过捕捉开发者的行为模式来展开竞争，正如首席执行官迈克尔·特鲁埃尔在Stratechery访谈中所指出的那样： 

本：这是否是你未来真正的可持续优势？凭借你所掌握的使用数据，你不仅能主导这一领域——而不仅仅是借助LLM起步——现在你还基于用户实际使用Cursor的情况，自主训练自己的模型。要知道，最初你能做到这一点，正是因为你掌握了完整的代码上下文；如今，你更拥有了专属的数据资源，足以进一步推动发展。 

迈克尔：是的，我认为这是一个巨大的优势。而且，这种高天花板的动态让你能够灵活地在不同产品之间选择，再加上第三种关键的分销模式，它能帮你收集到宝贵的用户数据，进而帮助你不断优化产品。事实上，这三点在90年代末和21世纪初的搜索引擎领域都曾普遍存在。因此，从很多方面来看，我们当前市场的竞争格局其实比普通的企业级软件市场更接近搜索引擎的模式。 

拆解所谓的封装器的本质
人工智能封装器的批评者和拥护者各执一词，但双方都忽略了一点。批评者指出，某些封装器缺乏竞争力，一旦平台吸纳其功能，便可能消失；而拥护者则认为，每家成功的软件公司背后，都离不开某种形式的包装。 

但我认为，真正的洞察力恰恰存在于这些立场之间。即使一种新应用最初只是个“包装型”产品，但如果它扎根于实际工作场景，直接对接企业专有的核心系统，自主积累数据并从用户使用中不断学习，甚至在行业巨头尚未整合相关功能之前就已抢占市场，那么它完全有可能长久立足。更重要的是，那些即便面对激烈竞争，仍能快速迭代、持续推出满足用户需求的功能的“封装型”产品，往往难以被对手超越。而这些特质，正是决定产品能否历久弥新，而非昙花一现的关键所在。
